# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

Older versions are not supported. Please upgrade to the latest 0.1.x patch.

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Use GitHub's private vulnerability reporting on this repository
(**Security** tab, then **Report a vulnerability**). Include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof-of-concept.
- Any suggested mitigations, if known.

## Response

This project is maintained on a best-effort basis with no committed SLA. You
can expect an acknowledgement within a few business days when possible. We will
work with you to understand the issue and coordinate a fix before public
disclosure (responsible disclosure).

We appreciate security research conducted responsibly and will credit reporters
in the release notes unless anonymity is requested.
